## Why the two numbers differ

`--sample 2` against a public endpoint is not a repeat measurement: run 1 retrieved one transaction
that failed outright and attributed nothing; run 2 retrieved a caller and 1.7 SOL. That is exactly the
behaviour the report is designed to show rather than hide — the score is computed from what came back,
`coverage` prints how much of the model that was, and `ceiling`/`unassessedAxes` stop a run from
claiming more than it saw. A ranking that did **not** move between these two runs would be the
suspicious one.

Reproduce with the two commands above. Expect the same 10/40 posture axis and the same two
`not assessed` lines, and expect the blast-radius number to depend on what the node returns that
minute.
